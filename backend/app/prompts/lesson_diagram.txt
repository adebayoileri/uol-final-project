Return at most 2 diagrams. Returning an empty list is a correct and common answer — most lessons about grammar, vocabulary, history or terminology are not helped by a picture. Only specify a diagram when it shows something the prose cannot: a spatial relationship, a structure, a process order, or a shape.

Choose ONE kind per diagram.

"board" — a square grid: a chessboard, a coordinate grid, a matrix.
  size: integer 4 to 8 (a chessboard is 8)
  pieces: [{{"at": "d4", "glyph": "N", "tone": "brand"}}]  — "at" is algebraic, file letter then rank digit
  highlight: ["e6", "f5"]  — squares to tint
  labels: true to show file and rank labels

"graph" — things joined by arrows: pipelines, binary trees, graphs, state machines.
  layout: "chain" for a single sequence of steps, "tree" for a hierarchy or binary tree,
          "layered" for a general directed graph, "circular" for a cycle
  nodes: [{{"id": "open", "label": "open(path)", "tone": "brand"}}]
  edges: [{{"from": "open", "to": "read", "label": "returns handle", "directed": true}}]
  A "tree" layout must be a real tree: exactly one root, every other node exactly one parent.
  A "chain" layout must be one straight sequence with no branching.

"plot" — curves, points or bars on labelled axes.
  x_label, y_label: strings
  x_range: [min, max]        y_range: [min, max] (optional)
  series: [{{"id": "s1", "label": "Sigmoid", "type": "function",
             "fn": {{"family": "sigmoid", "params": {{"k": 1}}}}}}]
    type is "function", "points" or "bars".
    "function" needs fn.family, one of: linear, quadratic, exponential, sigmoid, sine, normal.
    "points" and "bars" need points: [[x, y], [x, y]].
  markers: [{{"id": "m1", "at": [0, 0.5], "label": "midpoint"}}]

"geometry" — a shape with labelled sides or angles.
  shape: "triangle", "rectangle", "polygon" or "circle"
  sides: [3, 4, 5] for a triangle (they must be able to form one), [width, height] for a rectangle
  radius: a positive number, for a circle
  vertices: ["A", "B", "C"] — required for "polygon" (3 to 8), optional elsewhere
  show_sides, show_angles: booleans
  annotations: [{{"at": "AB", "text": "hypotenuse"}}]

Every diagram also needs:
  id: a short unique slug
  title: a few words, read aloud by screen readers
  caption: one sentence saying what the reader should take from it

Optionally add a staged reveal with "steps" — 2 to 6 of them, each {{"label": "...", "show": [...], "highlight": [...]}}.
The ids in show and highlight must be elements that exist in the diagram: a square name like "e6" for a board, a node id or "from->to" for a graph, a series or marker id for a plot, a vertex like "A" or a side like "AB" for geometry. Use steps only when the order genuinely teaches something.
